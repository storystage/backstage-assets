# Backdrop originals

The pictures `sources/backdrops.json` makes the stage's grounds and picture skies from (storystage2's spec 17, section 2), as fetched on 10 November 2026. They are kept here so the build fetches exactly what was reviewed, pinned to the commit that added them. All are CC0 (storystage2's `docs/legal/licence-audit.md`: ambientCG and Poly Haven, ship).

**Grounds** are ambientCG's 1K colour maps, byte for byte from each material's zip. The build matches each one's colour to the stage's flat colour for its ground.
