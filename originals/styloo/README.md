# Styloo originals

These are the seven animals of [Animals Asset Pack by styloo](https://styloo.itch.io/animals), exactly as the pack's `glb/` folder holds them. The owner bought the pack on itch.io on 18 November 2026 at its minimum price of $3. The pack's page gives its asset licence as **Creative Commons Zero v1.0 Universal** (CC0), and the author confirms that in the page's comments. The owner chose to keep the originals here, public and credited (18 Nov 2026), so the build can fetch them pinned to the commit that added them. Each file's SHA-256 matches the pack's own file. The files are renamed to plain English; the pack's own names are in the table.

Every model is CC0, credited "<Animal> by styloo, Animals Asset Pack (CC0)" in `backstage.json` (storystage2's `docs/legal/licence-audit.md`). If you find these useful, the author asks for a small donation on itch.io.
