# KayKit Forest Nature Pack originals

28 models of Kay Lousberg's **KayKit Forest Nature Pack 1.0**, free tier ([kaylousberg.itch.io/kaykit-forest](https://kaylousberg.itch.io/kaykit-forest)), which its `License.txt` (kept here) places under **CC0 1.0 Universal**. The owner chose the Grass_2, Rock_3 and Tree_Bare series on 21 Nov 2026, from a sheet of all 101, and left the rest out. Each is credited "<model> by Kay Lousberg, KayKit Forest Nature Pack (CC0)" in `backstage.json` (storystage2's `docs/legal/licence-audit.md`: KayKit, ship).

The pack came from itch.io's free download in the owner's Chrome on 21 Nov 2026 (`KayKit_Forest_Nature_Pack_1.0_FREE.zip`, SHA-256 `2ee83e63bb7695f2d884ec27ddf6fce020789a452e7d5c5b0bbdfc4f6ea1fc8c`). The pack has no copy on GitHub, so these files are kept here exactly as they are in its `Assets/gltf` folder, so the build can fetch them pinned to the commit that added them. Every model shares `forest_texture.png`, one gradient picture.
