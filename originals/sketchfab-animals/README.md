# Sketchfab animals (CC BY 4.0)

These are 23 rigged, animated animal models from Sketchfab, each under **Creative Commons Attribution 4.0** (CC BY 4.0), as its page said when it was downloaded, with the owner's permission, on 18 November 2026 (the owner's choice of 18 Nov 2026: rigged models where they exist). Each file is the GLB the page offered, kept exactly as downloaded so the build can fetch it pinned to the commit that added it, except the horse (below). They're renamed to plain English. Each file's SHA-256 is in the table.

The build credits each one "<title> by <maker>, CC BY 4.0, via Sketchfab, changed for StoryStage" in `backstage.json`, since it reduces every model, renames bones and keeps only the standard clips (storystage2's `docs/legal/licence-audit.md`). The sheep's credit also names the model it animates, "Nz Inbred Sheep" by MightyGangsta13 (CC BY 4.0), as its page asks.

**The horse** came as a GLB with an untextured material and its coats as separate pictures. `horse.glb` is that GLB with "Horse Brown.png" put in as its material's colour texture, and nothing else changed. The download's `Horse.glb` was `ecc058b83dd202e168f6e5cd23edf7ccc85d54d1e3b9b6d00bc82a4fd8ad9e31`, and `Horse Brown.png` was `969c244efcd5c3c48d3e8a7d23396330827484ca1b1595e93ff60c461a568785`.
