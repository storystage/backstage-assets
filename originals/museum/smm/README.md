# Scottish Maritime Museum originals

The Scottish Maritime Museum's models that `sources/museum.json` lists, as downloaded on 11 November 2026 from Sketchfab, each as "GLB, texture size 1k". Each item's own page shows CC0 Public Domain (Sketchfab's public-domain dedication for cultural organisations) and notes no third-party rights, as storystage2's licence audit asks (museum scans: ship per item). They are kept here because Sketchfab lets only a signed-in account download, so the build can't fetch them itself; the build fetches them from this repository, pinned to the commit that added them.
