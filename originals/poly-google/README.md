# Poly by Google originals

74 low-poly models from Google's Poly library, as Poly Pizza served them on 21 November 2026 (the owner's choices of that day, from a sheet of 74 shortlisted by S4): animals for the gaps in the rigged cast, plants, vegetables and fruit, and a few space props. Each is by "Poly by Google" or "jeremy" (a Poly team account) under **CC BY 3.0**, as its Poly Pizza page shows. They are kept here because Poly Pizza's file server refuses GitHub's build runners, so the build fetches them from this repository, pinned to the commit that added them. Each file's SHA-256 matches what was fetched.

The animals have no skeleton yet: they join the cast with no joints (they move and turn, but don't walk) until the four-legged autorig gives them one. The build credits each "<title> by <maker>, CC BY 3.0, via Poly Pizza" (storystage2's `docs/legal/licence-audit.md`, Poly Pizza: ship per item).
